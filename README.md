# Team Task Manager\n\nA full-stack task management app with role-based access control, project and team management, task assignment, status tracking, and dashboard reporting.\n\n## Features\n\n- Authentication with signup/login and JWT sessions\n- Project creation with Admin/Member roles\n- Add project members by email\n- Task creation, assignment, status updates, and overdue tracking\n- Dashboard summary of total, pending, in progress, completed, and overdue tasks\n- REST API backend with JSON-backed NoSQL storage and Express\n- Frontend served from static `public` assets\n\n## Local setup\n\n1. Install dependencies\n\n```bash\ncd c:\\Users\\batti\\OneDrive\\Desktop\\Task_Manager\n npm install\n```\n\n2. Copy environment file\n\n```bash\ncopy .env.example .env\n```\n\n3. Start the app\n\n```bash\nnpm run dev\n```\n\n4. Open `http://localhost:4000` in your browser\n\n## Deployment\n\nThis project is ready for Railway deployment. Railway will automatically install dependencies and run `npm start`.\n\n### Railway setup\n\n1. Create a new Railway project\n2. Connect the repository or upload the files\n3. Add environment variables:\n   - `JWT_SECRET`\n   - `DB_FILE` (optional, default is `data.json`)\n4. Deploy the app\n\n## API Endpoints\n\n- `POST /api/auth/signup`\n- `POST /api/auth/login`\n- `GET /api/auth/me`\n- `GET /api/projects`\n- `POST /api/projects`\n- `GET /api/projects/:projectId`\n- `POST /api/projects/:projectId/members`
- `DELETE /api/projects/:projectId`\n- `GET /api/projects/:projectId/tasks`\n- `POST /api/projects/:projectId/tasks`\n- `PUT /api/tasks/:taskId`\n- `DELETE /api/tasks/:taskId`\n- `GET /api/dashboard`\n\n## Notes\n\n- The app uses JSON-backed NoSQL storage for local development, but the backend structure supports relational logic and can be extended to PostgreSQL.\n- For a production deployment, Railway can be used with PostgreSQL by switching the DB layer and connection string.\n
